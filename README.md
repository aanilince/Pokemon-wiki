## Features

- Browse Pokemon information
- Search for your favorite Pokemon
- View detailed Pokemon stats and abilities

## Technologies

- React
- Vite
- Tailwind CSS

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
